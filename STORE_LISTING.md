Most Simple MD Reader

Read, write and save markdown without leaving your browser.

Drag and drop an .md file into the dropzone (or use "Browse") and it opens rendered in a new tab.

Want to write instead? Type or paste markdown straight into the big built-in editor, hit Render to see the result in a new tab, and hit Save to write your text back to a file with the standard Chrome file picker. Pick any folder on your computer - or a folder inside a cloud drive that is synced to your computer (Google Drive, OneDrive, Dropbox, ...) - and the file is stored there. After the first save, Ctrl+S keeps writing to the same file (Shift+Ctrl+S always opens the picker for "Save as").

Your text is autosaved as a local draft, so you never lose work when you close the tab.

Supports dark & light mode.

No account, no server, no tracking: everything happens locally in your browser.
